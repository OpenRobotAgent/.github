### 从理解，到行动，再到验证

**Open Robot Agent（ORA）** 探索如何将通用多模态 Agent 的推理与软件工具能力延伸到机器人所处的物理世界。

我们关注三个相互联系的方向：

- **通用智能**：将场景理解、空间推理、操作判断与长程规划联系起来。
- **可信执行**：由 Harness 连接模型与机器人；物理约束、安全和运动控制由可信执行系统负责。
- **真实反馈**：通过真实观测与执行证据核对行动结果，并据此调整下一步决策。

**长期方向**：可信机器人交互 → 可验证的真实经验 → 更通用的物理智能。

> **当前状态**：ORA 仍处于研究与原型开发阶段。上述能力和长期方向不构成已经实现或验证的功能声明。核心研究源码、未发表的方法与内部实验材料暂不公开；此处仅展示可公开的项目愿景。

<summary><strong>English overview</strong></summary>

**Open Robot Agent (ORA)** explores how general-purpose multimodal agents can understand, act, and adapt in the physical world.

Our research direction brings together **general intelligence**, **trusted robot execution**, and **feedback grounded in observed outcomes**. We aim to develop verifiable interaction experience that can inform more capable embodied agents.

This is an ongoing research initiative, **not a claim of completed or validated general-purpose robotic capabilities**. Core research code and unpublished methods remain private for now.
